由GGB入門 深入學習Python!

大家都知道有資訊能力很重要，但是卻常常苦無入門的方式，或是，看似孩子已經去學了程式語言，但卻都只能在課堂上，依樣畫葫蘆，只會做老師當堂教的東西，卻不知道要如何靈活應用所學做為解決問題的輔助工具。這裡，#獵豹朱安強博士 解答大家心中的疑惑，也利用的CM01/02課程安排，帶領孩子們正確學習的方向，先打下學習程式語言穩固的基礎，接著再漸進的深入，讓孩子利用資訊和數學能力，來解決問題！

【文 、影片】by 獵豹朱安強博士

最近有家長問我國一生對程式有興趣要不要直接來學 Python ，為了回答這個問題我還是來錄製一個影片來說明。

其實這兩、三年也有數學老師跟我說想直接學 Python ，跳過 GGB的任務 。有時也不好意思直接跟他說，你沒有訓練拆解問題的能力。你學了 Python 就會停在 Hello World 。其實我當時大學學了 C++ 也就是這樣。看了懂些基本程式語法。但其實沒有具備拆解問題的能力。就無法寫出幾個可協助我探究數學的程式。

先回到結論：我建議先學 Geogebra 的主要理由是，Geogebra 可快速做出些可交互性的作品。而『創作』我認為是給學習者很強的支持動力。在用 Geogebra 創作時，是可訓練很多問題拆解的想法，在使用 Geogebra 的腳本，也是會磨練很多程式撰寫的能力。這些都是可遷移到未來其他程式語言的學習。初學者要學 Python 做出有視化的東西那路途的確長很多。

==== 關於影片的腳本 如下 =====

國中生該學 Python 還是 Geogebra 呢？我先用我在 CM02 正講到一個 Python 來談起，『分析 1000 內的所有數的因數個數』。用 Python 處理很方便，在半小時內就可看到 Python 統計出 1000 內的因數個數分佈，也可繪製出圖表。不過，這對大多數剛升國一生來說其實是蠻有挑戰。最大的挑戰可能就是有不少的指令代碼語言。

因為 Python 是以全指令來與電腦溝通。大量英文指令輸入很容易讓國一生覺得程式好難。其實學生能力還沒到位，早學反而有不好的效果。我常說 GGB 的作品要用 Python 也可以做出來，但對初學者就不是那麼方便。GGB 有很多基礎工具，他有按鈕直接點按，但每次點按，也都會有相對應的代碼指令。這就可讓你搭配 Sequence 與腳本來作些大量重複的效果。而 GGB的 數值滑桿，也很快就有產生動態可交互的圖形。

學程式不是學語法而是要學拆解問題的能力。那在學拆解問題前，有哪些是程式的基本思維呢？一般來說『迴圈、判斷、函式』是學程式最重要建立的思維，那有沒有讓小學生學習這三個思維概念，又不用大量英文指令呢。 就是個很棒的工具。

但學完 的積木拖拉程式，對於後期要學 Python 還是有巨大的門檻。有沒有一種介於 Python 與 之間可讓學生更好理解程式思維又可快速產生可交互可視化的作品呢！我想數學軟體 Geogebra 就是個很合適的工具。可惜一般程式教師比較少深入接觸這軟體，往往以為這只是繪製函數圖像與幾何圖形，並沒有發覺到這可搭配指令腳本，做到很多中學程式教育想要達到的程式思維，更重要的是這工具還可結合中學數學，在學程式的同時，同時強化中學數學的理解，並體會到數學是這麼有用。

最後，回到國一生是否合適學 Python 呢？我認為這個用年紀來分割的問法不是很恰當，要依思維能力來作分割比較合適。如果學生對用指令與電腦溝通的思維還沒建立，那就歡迎從 CM01 來培養用指令與電腦溝通的思維訓練。若學生已對國中的函數、變數、數列思維都已具備，且能駕馭大量英文指令的輸入，那也可來加入 CM02 的課。（補充一下，其實目前 CM02 的課也有幾位是小學生就來參與，且作業都做得很傑出。）

當然若完全沒程式的訓練，我想 CM01 就是個很好的開始，我也預計在 CM01 後，再開個對國中生的 Python 的基礎課。所以重要的不是中學生何不合適，而是你是否具備學 Python 的能力。如果你在兩個月的 CM01 有打下不錯的基礎，那你就有機會挑戰這個國中生的 Python 入門課，讓我們用 Python 來解決問題，同時體驗到與電腦溝通，數學是如此的有用。
